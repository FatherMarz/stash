stash_

A tiny secrets store for AI agents. One Go binary, encrypted local storage.

GitHub →

Paste the setup instructions to your agent. It installs stash and prepares the connection commands for you to run.

Quick start

go install github.com/FatherMarz/stash@latest

stash setup                        # once, in your terminal: owner token, paths, AWS
stash serve
stash set OPENAI_API_KEY           # paste the value in your terminal
stash list                         # proxy, direct, or blocked
stash run --secret OPENAI_API_KEY -- python agent.py

Access with clear limits

Proxy. Supported API connections give the program a substitute token. stash adds the real key before forwarding to the configured service. Connected AWS profiles use stash to sign supported requests.

Direct. A program can need a real database password or signing secret. You must approve a direct connection first. Captured output masks matching values of at least eight bytes. This does not prevent deliberate disclosure.

Blocked. Unconfigured secrets stay blocked. Each run must name its required secrets with --secret. A blocked selection stops the entire run before the program starts.

One setup, two tokens

Your agent prepares setup and connection commands. You run the owner commands and enter secret values in your own terminal. stash setup shows the owner token once and stores an agent token for the CLI. Agents do not need your owner token.

The local agent workflow supports macOS and Linux. Each scoped run gets its own token, which ends when the program exits.

stash aws connect my-profile --key-id MY_KEY_ID --secret-key MY_SECRET_KEY
stash route create service --upstream https://api.example.com --secret SERVICE_KEY
stash route create database --secret DATABASE_URL --direct
stash audit                        # who used what, when

Use proxy connections for API keys. Approve direct access only when a program must hold the real value.

Notes

  • Secrets use AES-256-GCM in ~/.stash/stash.db. The default encryption key sits beside it in ~/.stash/stash.key. Back up both. stash does not isolate an agent that can read those files or control your OS account.
  • stash listens on 127.0.0.1 by default. Remote server access requires a custom address and TLS. Agent-token access remains local.
  • AWS presigned URLs, signed-chunk uploads, API Gateway and signed bodies over 256 MB are unsupported.
  • Existing unscoped scripts need explicit secret selections. Unconfigured values now require owner-approved connections.
  • stash help lists every command. Each command maps to an HTTP route under /v1/.
  • An agent skill ships in the repo. It teaches Claude Code (or any agent) how to use stash.
  • No web UI, no rotation, no clustering. If you need those, use Infisical or OpenBao.
