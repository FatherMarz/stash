stash_

A tiny secrets store for AI agents. One 7 MB binary, one encrypted file.

GitHub →

Copy for LLM puts setup instructions on your clipboard. Paste them to your agent and it installs stash for you.

Quick start

go install github.com/FatherMarz/stash@latest

stash setup                        # once, in your terminal: owner token, paths, AWS
stash serve
stash set OPENAI_API_KEY           # paste the value in your terminal
stash list                         # each secret and its path
stash run -- python agent.py       # the agent gets its secrets, never your API keys

Two paths for agents

Proxy. API keys and AWS keys never reach the program. The program gets a run token. stash adds the real key on the way out, and only to that key's own site. For AWS, the profile sends each call through stash, and stash signs it.

Hand-over. Database URLs, signing secrets and .env files reach the program as real values, because the program needs them. stash prints them as **** in output. A program that wants to leak one still can, so keep every API key on the proxy.

One setup, two tokens

stash setup gives you the owner token once and sorts every secret into its path. Agents need nothing: the agent token works only through the stash program, so a copy in curl does nothing. Each stash run gets its own run token, which ends when the program exits.

stash aws connect my-profile --key-id MY_KEY_ID --secret-key MY_SECRET_KEY
stash route create service --upstream https://api.example.com --secret SERVICE_KEY
stash audit                        # who used what, when

Notes

  • Secrets are AES-256-GCM encrypted in ~/.stash/stash.db. The key is ~/.stash/stash.key. Back up both. Keep them apart.
  • stash listens on 127.0.0.1 only. If you expose it, add --tls-cert and --tls-key.
  • stash help lists every command. Each command maps to an HTTP route under /v1/.
  • An agent skill ships in the repo. It teaches Claude Code (or any agent) how to use stash.
  • No web UI, no rotation, no clustering. If you need those, use Infisical or OpenBao.
